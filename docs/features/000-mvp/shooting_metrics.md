# Shooting Target Image Metrics for Mobile App

## 1. Core Scoring Metrics

-   Total Score
-   Average Score per Shot
-   Score Distribution
-   Group Score (best N shots)

## 2. Precision & Accuracy Metrics

-   Group Size
-   Mean Point of Impact (MPI)
-   Distance from Center
-   Extreme Spread
-   Standard Deviation

## 3. Shot Pattern Analysis

-   Shot Dispersion Pattern
-   Clustering Detection
-   Flyers Detection
-   Radial Distribution

## 4. Temporal / Session Metrics

-   Shot Order Tracking
-   Heatmap Over Time
-   Consistency Trend

## 5. Advanced Metrics (Used in Some Apps)

-   CEP (Circular Error Probable)
-   MOA (Minute of Angle)
-   Hit Probability
-   Confidence Ellipse

## 6. Visualization Outputs

-   Heatmaps
-   Shot Group Overlay
-   Trend Graphs
-   Radial Charts

## 7. Examples of Existing Apps Features

Common apps like ShotMarker, TargetScan, and Ballistic-X include: -
Automatic shot detection from images - Group size calculation - MOA
calculation - Session history tracking - Environmental annotations
(wind, distance)

## 8. Recommendations for Your App

Start with: 1. Score detection 2. Group size 3. MPI 4. Distance from
center

Then add: - Heatmaps - CEP - Trend analysis
